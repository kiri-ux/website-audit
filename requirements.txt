# PINNED TO THE BASE IMAGE'S OWN VERSION, and here on purpose.
#
# This said "deliberately NOT listed — the base image already ships it", and
# the reasoning was sound: reinstalling can drag the Python package past the
# Chromium baked into the image and produce a confusing "executable doesn't
# exist" at runtime.
#
# It was also, in production, wrong. The worker reported
#
#     Playwright is not importable on this worker: No module named 'playwright'
#
# so the consent scan fell back to parsing raw HTML on every single run, and
# five checkpoints went unanswered for weeks. Whatever the base image ships,
# what mattered was whether the interpreter that runs our code can import it —
# and nothing checked.
#
# The version is pinned to the SAME 1.42.0 the image is built from, so the
# package and the browsers at PLAYWRIGHT_BROWSERS_PATH stay in step and the
# original concern does not come back. Moving to a newer base image means
# moving this line with it.
playwright==1.42.0
